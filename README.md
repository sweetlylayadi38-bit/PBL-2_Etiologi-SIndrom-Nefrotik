# Etiologi Sindrom Nefrotik pada Anak

Presentasi gulir (scroll) untuk Tugas Mandiri PBL ke-2, Modul Ginjal dan Cairan Tubuh. Tiga belas adegan, dari sawar filtrasi glomerulus sampai penalaran etiologi pada kasus Andi. Setiap adegan terkunci di layar, lalu ilustrasi dan penjelasannya berganti tahap demi tahap saat halaman digulir.

## Cara memakai

- Buka halaman GitHub Pages repo ini.
- Tekan `Spasi` atau `↓` untuk maju satu tahap, `↑` untuk mundur. Remote presenter (PageDown/PageUp) juga bisa dipakai.
- Klik ilustrasi untuk memperbesar, atau tombol **Adegan** untuk lompat antar-adegan.
- Tautan langsung ke adegan tertentu: tambahkan `#adegan-4` (ganti angkanya) di akhir alamat.
